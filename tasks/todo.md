# Build checklist

- [x] Protocol/config/security: strict messages, traversal, sensitive paths, redaction tests.
- [x] Tools: exploration/search, Git, guarded edits, patch, rename/delete, backups and dry-run tests.
- [x] Commands: approval, timeout, bounded output, cancellation tests.
- [x] Agent: multi-step loop, corrections, deduplication, state, resume and audit tests.
- [x] Browser: persistent Edge, manual authentication, isolated turns, complete responses, probe (implemented; live checks below).
- [x] CLI: all requested commands; real local browser fixture checks.
- [x] Delivery: Windows scripts, sample, opt-in live suite, docs, build, audit and source packaging.
- [ ] Account-bound acceptance: real login/reuse/read/edit/failing-test repair (requires operator).
