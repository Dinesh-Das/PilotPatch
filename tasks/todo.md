# Build checklist

- [ ] Protocol/config/security: strict messages, traversal, sensitive paths, redaction tests.
- [ ] Tools: exploration/search, Git, guarded edits, patch, rename/delete, backups and dry-run tests.
- [ ] Commands: approval, timeout, bounded output, cancellation tests.
- [ ] Agent: multi-step loop, corrections, deduplication, state, resume and audit tests.
- [ ] Browser: persistent Edge, manual authentication, isolated turns, complete responses, probe.
- [ ] CLI: all requested commands; real local browser fixture checks.
- [ ] Delivery: Windows scripts, sample, opt-in live suite, docs, build, audit and ZIP.
- [ ] Account-bound acceptance: real login/reuse/read/edit/failing-test repair (requires operator).
